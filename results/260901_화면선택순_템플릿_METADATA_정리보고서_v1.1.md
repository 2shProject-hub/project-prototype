# K-Chao 프로토타입 [화면선택순] 템플릿(액티비티)별 METADATA 요구사항 정의서
본 문서는 K-Chao 리뉴얼 프로토타입 에뮬레이터의 **'화면선택' (ScreenComboBox)** 드롭다운에 등록된 전체 템플릿 순서와 1:1로 일치하도록 구성한 METADATA 요구사항 분석 보고서입니다.
각 템플릿을 구성하기 위해 백엔드(어드민/API)로부터 공급받아야 하는 필수 METADATA 항목과 함께, 기획 및 API 스키마 정의 시 확인이 필요한 항목을 **[확인 필요]** 로 명시하였습니다.

---

## 1. 1. 홈 화면 / 코스 안내 (`HomeScreen`)
- 컴포넌트: `HomeScreen` (id: `home`)
- 필요 METADATA 항목:
  - 레슨 기본 정보:
    - 레슨 번호 (예: '1과')
    - 레슨 타이틀 (예: '저는 흐엉이에요')
    - 레슨 요약 설명 (한국어 / 베트남어)
    - 레슨 썸네일 이미지/일러스트 URI
  - 차시(세션) 타임라인 목록:
    - 차시 ID / 번호 (1, 2, 3...)
    - 차시 타이틀 (한국어 / 베트남어)
    - 차시 구분 라벨 (한국어 / 베트남어, 예: '문법과 표현', '학습 성과')
    - 핵심 표현/요약 텍스트 (예: '저는 N이에요/예요')
    - 잠금 상태 여부 (isLocked)
  - 전체 코스 탭:
    - 코스 목록 (코스명, 레벨, 썸네일, 수강 상태 등)
- **[확인 필요]**:
  - 차시별 진도율 및 완료 상태 계산 방식 (클라이언트 로컬 누적 vs 서버 진도 동기화 API)
  - 상단 번개 배지(연속 학습일/스트릭 또는 포인트) 연동 API 데이터 규격

## 2. 2-1. 학습 미션(튜터) (`MissionTutorStage`)

  - 상단 일러스트/사진 썸네일 이미지 URI
  - 학습 미션 메인 타이틀 (한국어 / 베트남어)
  - 학습 목표 불릿 리스트 (한국어 배열 / 베트남어 배열)
  - AI 튜터 오버레이 데이터:
    - 튜터 아바타 썸네일 이미지 URI
    - 튜터 안내 음성 파일 URI (진입 시 자동 재생)
    - 튜터 말풍선 대사 리스트 (베트남어/한국어 문장 배열)
- **[확인 필요]**:
  - 교재 연계 메타데이터 (교재 페이지 'p16, p20-21', 과제물명 '내 프로필 카드' 등)의 실제 화면 표기 여부

## 3. 2-W. 단어 슬라이드 (`WordIntroSlidesStage`)
- 컴포넌트: `WordIntroSlidesStage` (id: `word-intro-slides`)
- 필요 METADATA 항목:
  - 슬라이드 공통:
    - 슬라이드 배열 (Min 1 ~ Max 10장)
    - 슬라이드 순서 번호
    - 슬라이드 유형 (`type`: 'intro' | 'quiz' | 'outro')
    - AI 튜터 안내 텍스트 (한국어 / 베트남어)
    - AI 튜터 음성 파일 URI (슬라이드 진입 시 자동 재생)
    - 튜터 아바타 이미지 URI
  - `intro` 타입 슬라이드:
    - 단어 카드 목록 (한국어 단어, 베트남어 번역, 단어별 발음 음원 URI, 카드 이미지)

    - 퀴즈 질문 텍스트 (한국어 / 베트남어)
    - 퀴즈 질문 음원 URI
    - 객관식 보기 목록 (보기 텍스트, 정답 여부, 선택 피드백)
  - `outro` 타입 슬라이드:
    - 완료 축하 타이틀 (한국어 / 베트남어)
    - 축하 메시지 및 완료 일러스트 이미지 URI
- **[확인 필요]**:
  - 백오피스 등록 방식 (단일 통짜 JSON vs ListItems 파싱) 및 슬라이드 최대 장수 제한 규격

- 컴포넌트: `GrammarDetailStage` (id: `grammar-detail`)
- 필요 METADATA 항목:
  - 문법 기본 정보:
    - 문법 배지 텍스트 (한국어 / 베트남어, 예: '문법과 표현 1')
    - 문법 타이틀 (한국어 / 베트남어, 예: '저는 N이에요/예요')
    - 핵심 문법 규칙 설명 문구 (한국어 / 베트남어)
  - 문법 강의 동영상:
    - 비디오 미디어 파일 URI / 스트리밍 URL (1080p MP4)
    - 비디오 썸네일 이미지 URI
  - 2열 규칙 비교 표 (Rule Table):
    - 좌측 규칙: 컬럼 헤더(예: '저는 받침 O + 이에요'), 예문 목록
    - 우측 규칙: 컬럼 헤더(예: '저는 받침 X + 예요'), 예문 목록
  - 보충 설명 (Supplement) 블록:
    - 도입 설명 텍스트
    - 세부 규칙 카드 목록:
      - 규칙 제목 및 설명 문구
      - 받침 유무 플래그 (`hasBatchim`)
      - 결합 쌍 목록 (`pairs`: `[{ word: '사람', ending: '이에요' }]`)
      - 하이라이트 적용 예문 목록 (`examples`: `[{ before: '저는 ', highlight: '학생이에요' }]`)
    - 받침 요약 매핑 표 (`summary`: `[['받침 O', '이에요'], ['받침 X', '예요']]`)
- **[확인 필요]**:
  - 동영상 자막(한국어/베트남어) 트랙 데이터(VTT 파일 또는 타임코드 JSON) 제공 여부
