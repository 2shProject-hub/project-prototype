# K-Chao 프로토타입 템플릿(액티비티)별 METADATA 요구사항 분석 보고서
본 문서는 K-Chao 리뉴얼 프로토타입에 구현된 전체 템플릿(액티비티)을 분석하여, 백엔드(어드민/API)로부터 공급받아야 하는 METADATA 항목을 정리한 보고서입니다. 각 템플릿의 화면 구성 요소, 다국어(한국어/베트남어) 데이터, 미디어(음원/이미지/영상), 퀴즈 및 평가 설정값 등을 분류하였으며, 기획 및 백엔드 스키마 정의 시 협의가 필요한 항목은 **[확인 필요]** 로 명시하였습니다.

## 1. 공통 및 코스/홈 영역

### 1-1. 홈 화면 / 코스 안내 (`HomeScreen`)
- 레슨 정보:
  - 레슨 번호 (예: '1과')
  - 레슨 타이틀 (예: '저는 흐엉이에요')
  - 레슨 요약 설명 (한국어 / 베트남어)
  - 레슨 히어로 썸네일 이미지 URI
- 차시(세션) 타임라인 목록:
  - 차시 ID / 번호 (예: 1, 2, 3...)
  - 차시 타이틀 (한국어 / 베트남어)
  - 차시 카테고리 라벨 (한국어 / 베트남어, 예: '문법과 표현', '학습 성과')
  - 차시 핵심 표현/문법 (예: '저는 N이에요/예요')
  - 차시 잠금 상태 여부 (isLocked / isUnlocked)
  - **[확인 필요]** 차시별 진도율 및 완료 여부 산출 방식 (클라이언트 로컬 저장 vs 서버 동기화 API)
- 전체 코스 탭:
  - **[확인 필요]** 전체 코스 목록 데이터 (코스 ID, 코스명, 레벨, 썸네일, 수강 상태 등 어드민 등록 API 규격)
- 사용자 상태:
  - **[확인 필요]** 상단 번개 배지(연속 학습일/스트릭 또는 포인트) 연동 데이터

## 2. 학습 도입 / 미션 / 인트로 / 퀵리뷰 영역

### 2-1. 학습 미션(튜터) (`MissionTutorStage` / `MissionStage`)
- 차시 정보:
  - 차시 번호 (예: 1)
  - 상단 차시 배지 텍스트 (한국어 / 베트남어, 예: '1차시 학습 목표' / 'Mục tiêu bài 1')
- 미션 콘텐츠:
  - 상단 일러스트/사진 썸네일 이미지 URI
  - 학습 미션 메인 타이틀 (한국어 / 베트남어)
  - 학습 목표 불릿 리스트 (한국어 배열 / 베트남어 배열)
- AI 튜터 오버레이:
  - 튜터 아바타 썸네일 이미지 URI
  - 튜터 안내 음성 파일 URI (자동 재생 음원)
  - 튜터 말풍선 대사 리스트 (베트남어/한국어 문장 배열)
- **[확인 필요]** 교재 연계 메타데이터 (교재 페이지 번호 'p16, p20-21', 과제물명 '내 프로필 카드' 등)의 실제 화면 표기 여부

### 2-2. 단어 슬라이드 (`WordIntroSlidesStage`)
- 슬라이드 공통:
  - 전체 슬라이드 개수 (Min 1 ~ Max 10장)
  - 슬라이드별 순서 번호
  - 슬라이드 유형 (`type`: 'intro' | 'quiz' | 'outro')
  - AI 튜터 안내 텍스트 (한국어 / 베트남어)
  - AI 튜터 음성 파일 URI (슬라이드 진입 시 자동 재생)
  - 튜터 아바타 이미지 URI
- 슬라이드 타입별 세부 데이터:
  - `intro` 타입: 단어 카드 목록 (한국어 단어, 베트남어 번역, 단어별 발음 음원 URI, 카드 이미지)
  - `quiz` 타입: 퀴즈 질문 텍스트(한국어/베트남어), 퀴즈 질문 음원 URI, 객관식 보기 목록(보기 텍스트, 정답 여부, 선택 시 피드백)
  - `outro` 타입: 완료 축하 타이틀(한국어/베트남어), 축하 메시지, 완료 일러스트 이미지 URI
- **[확인 필요]** 슬라이드 템플릿의 백오피스 JSON 스키마 등록 방식 및 최대 슬라이드 장수 제한 규격

### 2-3. 퀵리뷰 (`QuickReviewStage`)
- 화면 정보:
  - 상단 배지 라벨 (한국어 / 베트남어, 예: '퀵 리뷰' / 'Ôn tập nhanh')
  - 안내 가이드 타이틀 문구 (한국어 / 베트남어)
- 문항 목록 (Min 1 ~ Max 10문항):
  - 문항 번호
  - 회상 질문/표현 텍스트 (한국어 / 베트남어 번역)
  - 문제 발음 음원 파일 URI
  - 정답 텍스트 및 정답 상세 해설 (한국어 / 베트남어)
  - **[확인 필요]** 이전 학습 차시 태그 (예: '1과 1차시 표현') 및 문항별 힌트 제공 여부
  - **[확인 필요]** 문항 응답('기억나요'/'기억이 안 나요')에 따른 학습자 복습 큐 적재 API 연동 여부

### 2-4. 학습 소개 - 문법과 표현 / 문법 퀴즈 (`IntroTutorStage`)
- 인트로 정보:
  - 상단 배지 텍스트 (한국어 / 베트남어, 예: '문법과 표현 1')
  - 대표 아이콘/이모지 또는 그래픽 이미지 URI
  - 메인 타이틀 (한국어 / 베트남어)
  - 서브 타이틀/학습 순서 가이드 (한국어 / 베트남어)
- 학습 성과(Achievement) 카드:
  - 라벨 (한국어 / 베트남어, 예: '학습 성과' / 'Kết quả học tập')
  - 달성 목표 설명 문구 (한국어 / 베트남어)
- AI 튜터 오버레이:
  - 튜터 아바타 썸네일 이미지 URI
  - 튜터 안내 음원 URI
  - 튜터 말풍선 대사 (한국어 / 베트남어)

### 2-5. 학습 소개 - 실전 평가 (`IntroEvalStage`)
- 인트로 정보:
  - 상단 배지 텍스트 (한국어 / 베트남어, 예: '실전평가' / 'Đánh giá thực tế')
  - 대표 아이콘 (🎤)
  - 메인 타이틀 (한국어 / 베트남어)
  - 서브 타이틀 (한국어 / 베트남어)
- 학습 성과 카드:
  - 학습 성과 라벨 및 달성 설명 (한국어 / 베트남어)
- AI 튜터 오버레이 (튜터 이미지, 음원, 말풍선 대사)

## 3. 어휘(단어) 학습 및 세트 평가 영역

### 3-1. 오늘의 단어장 (음성) (`VocabWordbookVoiceStage` / `VocabWordbookStage`)
- 헤더 및 배지:
  - 상단 배지 및 타이틀 (한국어 / 베트남어, 예: '오늘의 단어')
- 어휘 목록 (약 10~15개 단어):
  - 단어 고유 ID
  - 한국어 단어 표기
  - 베트남어 번역 표기
  - 원어민 발음 음원 파일 URI
  - **[확인 필요]** 품사 태그 또는 단어 부가 설명 필드 포함 여부
- 기능 설정:
  - 지원 배속 옵션 (0.5x, 1.0x, 1.5x)
  - **[확인 필요]** 단어장 화면에서 발음평가 모달 직행 지원 여부

### 3-2. 단어장과 발음평가 (`SetWordbookEvalStage`)
- 세트 메타데이터:
  - 세트 번호 및 전체 세트 수 (`setNumber`, `totalSets` - 예: 1/3, 2/3, 3/3)
  - 상단 캡슐 배지 텍스트 (한국어 / 베트남어, 예: '단어장 1/3')
  - 메인 타이틀 (한국어 / 베트남어, 예: '핵심 어휘를 확인해요.')
  - 서브 타이틀 (한국어 / 베트남어)
- 세트 1 전용 안내 토스트 팝업:
  - 토스트 안내 메시지 (베트남어 텍스트)
  - 토스트 안내 음원 파일 URI
- 보기 모드 탭 (전체 보기 / 한국어 보기 / 베트남어 보기 텍스트)
- 세트별 어휘 목록 (세트당 Min 1 ~ Max 5개 어휘):
  - 단어 ID
  - 한국어 단어
  - 베트남어 번역
  - 원어민 발음 음원 URI
- 발음 평가 모달:
  - 원어민 모범 음원 URI
  - **[확인 필요]** AI 발음 평가(STT) 엔진 연동 메타데이터 (인식 대상 정답 텍스트, 평가 임계치, 정확도/유창성/완성도 산출 가중치)

### 3-3. 단어 만들기 (`WordBuildStage`)
- 퀴즈 문항 목록 (예: 5문항):
  - 문항 ID / 번호
  - 정답 한국어 단어 (음절 단위로 자동 분절되어 슬롯 생성, 예: '베트남')
  - 베트남어 번역 (예: 'Việt Nam')
  - 방해 글자 타일 목록 (Distractor Tiles 배열, 예: ['한', '프', '중'])
  - 단어 발음 음원 파일 URI
  - **[확인 필요]** 힌트 텍스트(국·베) 필드 필요 여부
- 활동 규칙 설정:
  - 최대 오답 허용 횟수 (`FAIL_MAX`, 기본값: 2회 후 정답 공개)
  - 키보드 직접 입력 모드 활성화 여부
  - 배속 설정값

### 3-4. 단어 빈칸 채우기 (`WordBlank1`)
- 문항 목록:
  - 문항 번호
  - 제시 베트남어 단어 (예: 'Việt Nam')
  - 빈칸이 포함된 한국어 단어 (예: '베___')
  - 정답 빈칸 문자열 (예: '트남')
  - 선택지 보기 목록 (4지 선다형 문자열 배열, 예: ['트남', '한국', '일본', '중국'])
  - **[확인 필요]** 정답 확인 후 단어 전체 발음 음원 파일 URI 제공 여부

### 3-5. 소리 듣고 단어 선택 (`ListenSelect1`)
- 문항 목록:
  - 문항 번호
  - 지시문 텍스트 (한국어 / 베트남어, 예: '다음 음성을 듣고 맞는 단어를 선택하세요')
  - 문제 발음 음원 파일 URI
  - 선택지 단어 목록 (3~4개 한국어 단어 배열)
  - 정답 단어 문자열
  - 세트 번호 및 전체 세트 수 (`currentSetNumber`, `totalSets`)

### 3-6. 베트남어 단어 보고 한국어 선택 (`WordVnKoSelect2`)
- 문항 목록:
  - 문항 번호
  - 문제 지시문 (한국어 / 베트남어)
  - 제시 베트남어 단어 (예: 'người')
  - 선택지 목록:
    - 한국어 단어 텍스트 (예: '사람')
    - 베트남어 보조 텍스트 (선택적)
    - 선택지별 발음 음원 URI
  - 정답 단어 문자열 (예: '사람')
- 세트 1 전용 안내 토스트 팝업 (안내 문구, 음원 URI)

### 3-7. 이미지 보고 단어 선택 (`PictureWord2`)
- 문항 목록:
  - 문항 번호
  - 지시문 텍스트 (한국어 / 베트남어)
  - 문제 이미지 URI (일러스트/사진)
  - 제시 베트남어 단어
  - 선택지 단어 목록 (3~4개 단어 배열)
  - 정답 단어 문자열
  - **[확인 필요]** 정답 단어 발음 음원 URI 포함 여부

### 3-8. 단어를 보고 음원 선택 (`WordSound1`)
- 문항 목록:
  - 문항 번호
  - 제시 한국어 단어 (예: '미국')
  - 베트남어 번역 텍스트 (예: 'Hoa Kỳ')
  - 음원 선택지 목록 (2x2 그리드, 4개 선택지):
    - 선택지 번호/인덱스 (1, 2, 3, 4)
    - 선택지별 발음 음원 파일 URI
  - 정답 선택지 번호 (1~4)
- 세트 1 전용 안내 토스트 팝업 (메시지, 토스트 음원)

### 3-9. 소리를 듣고 빈칸을 채우기 (`WordLetterBlank`)
- 문항 목록:
  - 문항 번호
  - 지시문 텍스트 (한국어 / 베트남어)
  - 문제 발음 음원 파일 URI
  - 정답 한국어 단어 (예: '미국')
  - 빈칸 슬롯 구성 (`slots`: `['_', '_']` 또는 `displayFormat`: `'___ ___'`)
  - 전체 제공 글자 타일 풀 (정답 글자 + 오답 방해 글자 타일 배열)
- 세트 1 전용 안내 토스트 팝업 (메시지, 토스트 음원)

### 3-10. 세트 학습 완료 (`SetCompleteStage`)
- 세트 메타데이터:
  - 현재 완료 세트 번호 및 전체 세트 수 (`setNumber`, `totalSets` - 예: 1/3, 2/3, 3/3)
- 화면 텍스트 (한국어 / 베트남어):
  - 1줄 타이틀 (예: '대단해요!' / 'Tuyệt vời!')
  - 2줄 완료 메시지 (예: '{N}세트 단어 학습을 완료했어요.')
  - 3줄 다음 단계 안내 (예: '다음 세트로 넘어갈까요?')
  - 하단 CTA 버튼 텍스트 (예: '다음 세트 학습하기 →')
- 사운드:
  - 진입 시 자동 재생 완료 축하 효과음/음원 파일 URI

## 4. 문법 및 문장 활동 영역

### 4-1. 학습 상세 소개 - 문법 (`GrammarDetailStage` / `GrammarStage`)
- 문법 기본 정보:
  - 문법 배지 텍스트 (한국어 / 베트남어, 예: '문법과 표현 1')
  - 문법 타이틀 (한국어 / 베트남어, 예: '저는 N이에요/예요')
  - 핵심 문법 규칙 설명 문구 (한국어 / 베트남어)
- 문법 강의 동영상:
  - 비디오 미디어 파일 URI / 스트리밍 URL (1080p MP4)
  - 비디오 썸네일 이미지 URI
  - **[확인 필요]** 동영상 자막(한국어/베트남어) 트랙 데이터 (VTT 또는 타임코드 JSON)
- 2열 규칙 비교 표 (Rule Table):
  - 좌측 규칙: 컬럼 헤더(예: '저는 받침 O + 이에요'), 예문 목록
  - 우측 규칙: 컬럼 헤더(예: '저는 받침 X + 예요'), 예문 목록
- 보충 설명 (Supplement) 카드:
  - 도입 설명 텍스트
  - 세부 규칙 카드 목록:
    - 규칙 제목 및 설명 문구
    - 받침 유무 플래그 (`hasBatchim`)
    - 단어-어미 결합 쌍 목록 (`pairs`: `[{ word: '사람', ending: '이에요' }]`)
    - 하이라이트 적용 예문 목록 (`examples`: `[{ before: '저는 ', highlight: '학생이에요' }]`)
  - 받침 요약 매핑 표 데이터 (예: `[['받침 O', '이에요'], ['받침 X', '예요']]`)

### 4-2. 문장 만들기 1 - 오디오 기반 (`SentenceBuildStage`)
- 문항 목록:
  - 문항 ID / 번호
  - 문제 문장 음원 파일 URI
  - 베트남어 지문 번역 (예: 'Tôi là người Hàn Quốc.')
  - 정답 한국어 문장 (예: '저는 한국 사람이에요.')
  - 정답 단어 분절 배열 (예: `['저는', '한국', '사람이에요']`)
  - 오답 방해 단어 타일 배열 (예: `['베트남', '의사예요']`)
  - 힌트 텍스트 (한국어 / 베트남어)
- 활동 규칙:
  - 최대 오답 허용 횟수 (2회)
  - 보기 선택 모드 / 키보드 입력 모드 지원

### 4-3. 문장 만들기 2 - 텍스트 기반 (`SentenceBuildStage2`)
- 문항 목록:
  - 문항 ID / 번호
  - 베트남어 원문 지문 카드 텍스트 (오디오 없이 텍스트 카드 제시)
  - 정답 한국어 문장
  - 정답 단어 분절 배열
  - 오답 방해 단어 타일 배열
  - 힌트 텍스트
- **[확인 필요]** 문장 만들기 1과 동일 문항 데이터를 사용하는지, 별도 문항 세트를 사용하는지 여부

### 4-4. 설명 슬라이드 (`SlideExplainStage`)
- 슬라이드 세트 (Min 1 ~ Max 10장):
  - 슬라이드 순서 번호
  - 슬라이드 이미지 URI (4:3 비율 일러스트/다이어그램)
  - 하단 캡션 설명 텍스트 (한국어 / 베트남어)
  - **[확인 필요]** 슬라이드별 나레이션 음원 파일 URI 제공 여부
- 완료 조건: 마지막 슬라이드 도달 시 [다음] 버튼 활성화

### 4-5. 문장 빈칸 채우기 (`SentenceBlank1`)
- 문항 목록:
  - 문항 번호
  - 베트남어 지문 문장 (예: 'Tôi là người Việt Nam.')
  - 빈칸 포함 한국어 문장 (예: '저는 _____ 사람이에요.')
  - 빈칸 정답 단어 (예: '베트남')
  - 객관식 선택지 단어 배열 (예: `['베트남', '한국', '일본', '중국']`)
  - **[확인 필요]** 문제 및 정답 문장 음원 파일 URI 제공 여부

### 4-6. 음원 듣고 입력하기 (`ListenTyping1`)
- 문항 목록:
  - 문항 번호
  - 청취 음원 파일 URI
  - 정답 텍스트 (한국어 또는 베트남어)
  - 번역 정답 텍스트 (한국어 또는 베트남어)
  - 힌트 텍스트 (예: '국가 이름', '사람을 뜻하는 단어')
  - **[확인 필요]** 텍스트 일치 채점 시 띄어쓰기/특수문자 허용 오차 규칙

### 4-7. 뜻에 맞는 문장 고르기 (`SentenceSelect1`)
- 문항 목록:
  - 문항 번호
  - 베트남어 원문 문장 (예: 'Tôi không phải là nhân viên công ty.')
  - 정답 한국어 문장 (예: '저는 회사원이 아니에요.')
  - 객관식 선택지 문장 목록 (3~4개 한국어 전체 문장 배열)
  - **[확인 필요]** 선택지 문장별 TTS 또는 오디오 음원 제공 여부

## 5. 대화 및 실전(듣기/말하기/쓰기/확인) 영역

### 5-1. 영상 브릿지 (`VideoBridgeStage`)
- 미디어 데이터:
  - 전체화면 비디오 파일 URI (세로형/가로형 MP4)
  - 비디오 자막 데이터 (한국어/베트남어 자막 VTT 또는 리스트)
- UI 텍스트:
  - 하단 CTA 버튼 텍스트 (한국어 / 베트남어, 예: '다음' / 'Tiếp theo')
- 제어 설정:
  - 비디오 자동 재생 여부 및 컨트롤러 노출 여부

### 5-2. 영상과 AI튜터 (`VideoAITutorStage`)
- 화면 정보:
  - 상단 배지 텍스트 (한국어 / 베트남어, 예: '실전 듣기')
- 미디어 데이터:
  - 영상 미디어 파일 URI 및 썸네일 이미지 URI
  - AI 튜터 아바타 썸네일 이미지 URI
  - AI 튜터 안내 음원 파일 URI (자동 재생)
  - AI 튜터 말풍선 대사 (한국어 / 베트남어)

### 5-3. AI튜터 설명 (`AITutorDescStage`)
- 화면 정보:
  - 상단 배지 텍스트 (한국어 / 베트남어)
- AI 튜터 데이터:
  - AI 튜터 아바타 이미지 URI
  - AI 튜터 음원 파일 URI
  - AI 튜터 말풍선 대사 (한국어 / 베트남어)

### 5-4. 듣고 말하기 상세 소개 (`ListenSpeakDetailEasyStage` / `ListenSpeakDetailStage`)
- 화면 배지 및 타이틀 (한국어 / 베트남어, 예: '듣고 말하기')
- 1단계 (잘 듣기 카드):
  - 대화 캐릭터 정보 (이름, 국기 뱃지/이미지)
  - 대화 미리듣기 오디오 파일 URI
- 2단계 (따라 말하기 카드):
  - 질문 말풍선 텍스트 (한국어 / 베트남어)
  - 내 대답 모범 말풍선 텍스트 (한국어 / 베트남어)
  - 마이크 발화 안내 텍스트
- **[확인 필요]** 초급(Easy) 2단 카드 레이아웃과 일반 상세 소개 레이아웃의 백오피스 템플릿 코드 분리 여부

### 5-5. 듣고 말하기 체험 가이드 (`ListenSpeakInteractiveTryStage`)
- 튜토리얼 스텝 데이터:
  - Step 1 (듣기 체험): 스피커 안내 문구(국·베), 체험 오디오 URI
  - Step 2 (말하기 체험): 마이크 안내 문구(국·베), 녹음 시뮬레이션 가이드
  - Step 3 (완료): 축하 배지 및 메시지
- **[확인 필요]** 1과 1차시 전용 1회성 온보딩 템플릿인지 일반 차시에도 재사용되는 템플릿인지 여부

### 5-6. 실전 듣기 (`PracticalListeningStage`)
- 화면 배지 (한국어 / 베트남어: '실전 듣기')
- 메인 문장 카드:
  - 한국어 문장
  - 베트남어 번역 문장
  - 문장 전체 원어민 발음 음원 파일 URI
- 핵심 단어 하이라이트 박스:
  - 핵심 단어 (한국어 / 베트남어)
  - 핵심 단어 개별 발음 음원 파일 URI
  - 핵심 단어 설명/의미

### 5-7. 실전 말하기 (`PracticalSpeakingStage`)
- 단계 배지 (예: '실전 말하기 · N/M')
- 문항 목록:
  - 한국어 빈칸 문장 (밑줄 빈칸 입력 영역 포함)
  - 베트남어 번역 문장
  - 정답 단어/표현
  - 힌트 텍스트 (한국어 / 베트남어)
  - 모범 발화 음원 파일 URI
- **[확인 필요]** 마이크 발화 녹음 후 실제 STT 채점 API 연동 여부 vs 단순 발화 연습 완료 처리 여부

### 5-8. 실전평가 - 음성 발화 (`SpeakingEvalStage`)
- 단계별 문항 목록 (총 4단계, 1/4 ~ 4/4):
  - 스텝 번호 및 전체 단계 수 (`step`, `totalSteps`)
  - 빈칸 포함 제시 문장 (한국어 / 베트남어)
  - 빈칸 슬롯 배열 (`blanks`):
    - 한국어 플레이스홀더 (예: '이름', '국적')
    - 베트남어 플레이스홀더 (예: 'tên', 'quốc tịch')
  - 모범 정답 문장 및 모범 발화 음원 URI
- **[확인 필요]** 음성 인식 및 점수 산출(발음/유창성)을 위한 AI 채점 엔진 파라미터 규격

### 5-9. 전체 대화 듣기 (`ConversationPreviewStage`)
- 화면 배지 (한국어 / 베트남어: '전체 대화 듣기')
- 대화 라인 목록 (`lines`):
  - 발화자 식별자 및 이름 (예: '민호', '유진')
  - 발화자 아바타 이미지 URI 및 말풍선 방향 (좌/우)
  - 한국어 발화 문장
  - 베트남어 번역 문장
  - 라인별 개별 음원 파일 URI
  - **[확인 필요]** 전체 대화 통합 1개 오디오 파일의 타임코드(시작/종료 초) 방식 지원 여부

### 5-10. 따라 말하기 (`ConversationShadowingStage`)
- 대화 라인 목록 (한 라인씩 순차 표시):
  - 발화자 정보 (이름, 아바타)
  - 원어민 모범 발화 한국어 문장
  - 베트남어 번역 문장
  - 원어민 발화 음원 파일 URI
- **[확인 필요]** 학습자 녹음 음성 저장 및 재청취 지원 여부

### 5-11. 실전 쓰기 - 대화 받아쓰기 (`DialogueListenWriteStage`)
- 문항 목록:
  - 문항 번호
  - 튜터/발화자 아바타 이미지 URI
  - 대화 음원 파일 URI
  - 정답 한국어 문장 (단어 단위로 자동 분절되어 단어 박스 슬롯 생성)
  - 베트남어 번역 지문
  - 💡 힌트 텍스트 (한국어 / 베트남어)
- 피드백 패널 데이터:
  - 음절 단위 비교 채점 결과 텍스트
  - 오답 시 정답 공개 및 재시도 옵션

### 5-12. 실전 확인 - 대화 빈칸 퀴즈 (`PracticeCheckStage`)
- 3개 세트 / 페이지 구성:
  - 세트 번호 (1/3 ~ 3/3)
  - 퀴즈 질문 타이틀 (한국어 / 베트남어)
  - 대화문 구성 (A 발화, B 발화):
    - A/B 발화 문장 텍스트 및 인라인 빈칸 위치
    - 빈칸별 단어 선택지 목록
    - 각 빈칸의 정답 단어
- 피드백 패널 데이터:
  - 세트 완료 시 오답 문장 나열 및 해설 텍스트

## 6. 문화 및 리포트/완료 영역

### 6-1. 문화 (`CultureStage`)
- 액티비티 정보:
  - 액티비티 번호 및 제목 (한국어 / 베트남어, 예: '한국의 인사 예절')
- 상단 히어로 미디어:
  - 미디어 타입 (`type`: 'image' | 'video')
  - 미디어 파일 URI
  - 캡션 텍스트
- 교재 연계 문화 콘텐츠 카드 목록:
  - 카드 제목 및 본문 내용 (한국어 / 베트남어)
  - 교재 번호별 세부 항목 리스트 (`subItems`: 번호, 한국어 설명, 베트남어 번역)
  - **[확인 필요]** 세부 항목별 첨부 이미지 URI 지원 여부
- 교재 연계 안내 텍스트 (예: '교재 p.28 참고')

### 6-2. 학습 리포트 (`LearningReportStage`)
- 차시 정보:
  - 차시 번호 및 타이틀 (한국어 / 베트남어)
  - 학습 요약 설명 문구 (한국어 / 베트남어)
- 학습 성과 요약 통계:
  - 학습 어휘 개수 (`vocabCount`)
  - 발음 평가 점수 / 총점 (`speakingScore` / `speakingTotal`)
  - 확인 문제 점수 / 총 문항 수 (`testScore` / `testTotal`)
- AI 종합 피드백:
  - AI 총평 코멘트 (한국어 / 베트남어)
- 재학습(다시 보기) 섹션:
  - 단어 다시 보기 링크 / 데이터
  - 문법 다시 보기 링크 / 데이터
  - 음성 다시 보기 링크 / 데이터
  - **[확인 필요]** 재학습 카드 터치 시 해당 액티비티로의 딥링크 라우팅 규격

### 6-3. 완료 축하 화면 시리즈 (`CompletionCelebration*`)
- 적용 화면: 단어 완료, 문법 완료, 수업 전체 완료, 실전 듣기/읽기/쓰기/확인 완료 (총 7종)
- 완료 메타데이터:
  - 축하 카테고리/단계명
  - 축하 메인 타이틀 (한국어 / 베트남어, 예: '대단해요!', '훌륭해요!', '수고했어요!')
  - 축하 상세 설명 (한국어 / 베트남어, 예: '오늘의 단어를 모두 학습했어요. 이제 문법을 배워볼까요?')
  - 하단 확인/다음 버튼 텍스트 (한국어 / 베트남어)
- 애니메이션/효과음:
  - 파티클 애니메이션 이펙트 (컨페티/이모지 파티클)
  - **[확인 필요]** 축하 완료 효과음 오디오 파일 URI

## 7. 백엔드 API 설계 시 핵심 점검 사항 요약 [확인 필요 총괄]

- 1. **다국어 필드 표준화**: 모든 사용자 노출 텍스트는 `koText` / `viText` (또는 i18n key-value) 쌍으로 공급되어야 함.
- 2. **미디어(Audio/Video/Image) 소스 경로**: 절대 URL 또는 백오피스 파일 관리 키(`mediaKey`) 체계 확립 필요.
- 3. **슬라이드형 템플릿 규격**: 단어 슬라이드(`2-W`), 설명 슬라이드(`14`)의 슬라이드 배열(Min 1 ~ Max 10) 백오피스 ListItems 컬럼 매핑 표준화.
- 4. **AI/STT 발음평가 연동 규격**: 발음평가(`5-2`, `15`, `22`, `대화-2`)에서 STT 채점 점수(정확도/유창성/완성도) 산출 방식 및 전송 페이로드 정의.
- 5. **학습 진행 및 리포트 통계**: 어휘 수, 발음 점수, 문제 풀이 정답률을 클라이언트에서 누적 집계하여 서버 리포트 API로 전송하는 생명주기 확립.
